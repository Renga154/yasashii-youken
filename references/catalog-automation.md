# 決めること一覧: 作業の自動化・スプレッドシート連携・ボット・ブラウザ拡張

「毎朝○○を集めて表にまとめて」「フォームの回答が来たらメールして」「LINEで返事をするボット」「ブラウザにボタンを足したい」など、決まった作業を自動でやらせる依頼で読む。
「当てはまる条件」の番号は SKILL.md の5条件(catalog-common と同じ)。「聞く」は候補で、絞り方は SKILL.md のステップ2に従う。A8・A10・A11 は、LINE・ブラウザ拡張・Slack を使うときだけ読む。金額はすべて 2026-10 時点の目安。
catalog-common と重なる項目: A1 は C1、A9 は C3 と同じ判断。自動化では A1 で聞いて C1 は使わない。A9 は C3 の答えをそのまま使い、聞かない。AI が文章を作る自動化では、人の確認(A2)は catalog-ai-feature の I5 の1問にまとめる(扱いは catalog-ai-feature の冒頭)。AI を使わない自動化では A2 で聞く。

## A0. 届くもの・できあがるものの中身と形
- **重さ**: 聞く(どの自動化でも聞く。見本を2〜3案並べた1問にまとめる)
- **当てはまる条件**: ②⑤
- **本人への聞き方**: 「毎朝届くのは、この3つのどれに近いですか?」(ステップ1の「完成のイメージ」から、何について・何件・1件の長さ・何時・送り主の名前まで入れた見本を、question-style.md の「見本の出し方」で見せる。フォームの知らせならメールの文面、表のまとめなら表の列、ボットなら返事の例、ブラウザ拡張なら押したあとの画面)
- **選択肢**(毎朝7時台に、ニュース5本を送り主「朝のニュース係」から LINE に届ける例):
  - A. 見出しとリンクだけ — 見え方: 1本1行で5行。気になるものだけ押して元の記事を読む / お金: 0円 / 注意: 中身は開かないと分からない / 後から変える: ◎
  - B. 見出し+配信元の紹介文+リンク — 見え方: 1本2〜3行。開かなくても何の話か分かる / お金: 0円 / 注意: 紹介文は配信元が配っている数行まで。記事の中身まではまとめない(A5) / 後から変える: ◎
  - C. 見出し+紹介文+AI のひとこと — 見え方: 各ニュースの下に「雑談で使うなら: …」のような一言 / お金: 月100円ほどまで(AI の利用料。消費税込みの多めの目安)。最初だけ、AI会社へのカード登録と約900円(5ドル)〜の前払いが要る(無料の範囲で使えるときは0円) / 注意: ひとことは AI の意見で、事実ではない。まちがうこともある / 後から変える: ◎
  - おまかせ → ステップ1の「何のため?」にいちばん合うもの(読む時間を減らしたいなら A、話題づくりなら C)
- **AI向けメモ**: 選ばれた見本を youken.md の「見本」に貼る。見本に描いた要素は全部「できること」に、この種類で当然ありそうだが描いていないもの(例: 過去の分を探す、届く時間を本人が変える)は「やらないこと」に書く。情報源(サイト名)は A5 の範囲で AI が選び、決めたことリストに並べる。件数・時刻・送り主の名前は見本どおりにし、決めたことリストに載せる。AI に文章を書かせるなら、料金(I2)と、まちがいの扱い・人の確認(I5。A2 もここにまとめる)は catalog-ai-feature の冒頭の扱いで決める。
- **完成チェック例**: 「確かめ用の[今すぐ送る]を押すと、1分以内に届いたものが、要件書の『見本』と同じ件数・並び・送り主の名前になっている」

## A1. 既製のサービスで済ませるか、つなぐサービスで組むか、専用に作るか
- **重さ**: 聞く(C1 の代わり。Google の中だけで済み、同じことができる既製のサービスもなく、ステップ1で設定は「一緒に見ながら」と答えていれば、AI が B に決めて記録)
- **当てはまる条件**: ①③
- **本人への聞き方**: 「この自動化、あとで自分で少し手直ししたくなりそうですか? それとも、一度ちゃんと動けばそのままでいいですか?」(なぜ聞くか: 自分で画面から直せるサービスを使うか、AI が専用に作るか、作らずに既製のサービスで済ませるかで、お金と直しやすさが変わります)
- **選択肢**:
  - A. つなぐサービスで組む(画面で「○○が来たら△△する」を組み立てるサービス) — 見え方: サービスの画面に「メールが来たら → 表に1行足す」のような流れが図で並び、自分でも直せる / お金: 月100〜1,000回ほどまでは0円。超えたら月約1,700円〜(ドル払い・税抜。2026-10時点の目安) / 注意: 回数が増えるほど料金も上がる。サービスの値上げや終了の影響を受ける / 後から変える: △ 流れはサービスの外に持ち出せず、組み直しになる(表の記録はそのまま使える)
  - B. AI が専用に作る(Google の中で動く小さなプログラムなど) — 見え方: いつものスプレッドシートに「実行」メニューやボタンが増える。中身はプログラムなので、直すときは AI に頼む / お金: 0円のことが多い / 注意: 1日に動ける時間やメールを送れる数に上限がある(A4) / 後から変える: △
  - C. 作らずに、既製のサービスで済ませる — 見え方: そのサービスの決まった形で今日から届く(例: Google アラートなら、決めた言葉の新着記事がメールで届く) / お金: 0円のものが多い / 注意: 届く形や中身はサービスが決めた範囲まで(LINE には届かない、など) / 後から変える: ◎
  - おまかせ → 既製のサービスで A0 の見本に近い形が届くなら C。Gmail・スプレッドシートなど Google の中で済むなら B。それ以外のサービス同士をつなぐだけで、本人が設定の画面を操作できるなら A の無料の範囲から(「一緒に見ながら」と答えていたら B)
- **AI向けメモ**:
  - 既製の候補(C): 情報のまとめ・お知らせなら Google アラート(無料・Google アカウントで登録。決めた言葉の新着がメールで届く https://support.google.com/websearch/answer/4815696?hl=ja )、ニュースアプリや新聞社の LINE 公式アカウント(無料。話題は選べない)、AI アプリの定期実行の機能(有料プランが多く、LINE には届かない。提供状況は要確認)。フォームの回答の知らせなら、Google フォームの回答のメール通知の設定で足りることが多い。
  - 本人向けの「月100〜1,000回」は Zapier Free 月100タスク・Make Free 月1,000クレジット、「月約1,700円〜」は Make Core の月払い($10.59、要確認)。
  - 料金(2026-10-02 確認): Zapier Free=月100タスク・2ステップの Zap のみ・15分ごとの確認、Pro=750タスクで $29.99/月(月払い)・$19.99/月(年払い) https://zapier.com/pricing 。成功したアクション1つ=1タスクなので、ステップ数×件数で見積もる。Make Free=月1,000クレジット・有効シナリオ2つ・最短15分間隔、Core=月10,000クレジット。公式で確認できたのは「$9/月」と「年払いで15%以上お得」の表示だけで、第三者情報では年払い $9・月払い $10.59(要確認) https://www.make.com/en/pricing 。n8n Cloud Starter €24/月(月払い)・€20/月(年払い)で月2,500回実行、Community Edition は自前サーバーなら無料(サーバー代は別) https://n8n.io/pricing/ 。IFTTT Free=アプレット2つ、Pro $2.99/月、Pro+ $8.99/月 https://ifttt.com/plans 。Power Automate は職場・学校の Microsoft アカウントなら無料ライセンスで標準コネクタのクラウドフロー(共有なし)が使える。有料は A4。
  - サービス間で流れの移し替えはできず、乗り換え=組み直し。無料枠の確認間隔(15分)で足りるかは A3 の答えで判断する。A を選んだら、サービスへの登録は本人の名義で「あなたにやってもらうこと」に入れ、最初の流れは AI が組んで、直し方を「使い始めてから」に書く。
- **完成チェック例**: 「試しにフォームから1件送ると、要件書に書いた時間内(Google の中で動かすなら1分、つなぐサービスの無料の範囲なら20分)に表に1行増える。A なら、サービスの画面を開くと流れが『○○が来たら△△する』と読める」

## A2. 間違って動いたときの被害を小さくする(確認の一手間)
- **重さ**: 条件次第(人に送る・消す・上書きする・買う・申し込むなど、取り消せない操作をするなら聞く。AI が文章を作る自動化では聞かず、I5 の答えから決めて記録する(冒頭))
- **当てはまる条件**: ②④⑤
- **本人への聞き方**: 「もしこの自動化が間違えて動いたら、一番困るのは何ですか? (例: お客さんに違うメールが届く、表の記録が消える、注文してしまう)」
- **選択肢**:
  - A. 毎回、確認してから実行 — 見え方: 自動で「下書き」や「送る予定の一覧」まで作り、あなたが[送る]を押したときだけ実行される / お金: 0円 / 注意: 毎回ひと手間かかる / 後から変える: ◎
  - B. 最初はお試しモード、慣れたら自動 — 見え方: 最初の1〜2週間は本番の相手ではなく自分宛てにだけ送り、「本番ならこうした」という記録を残す。問題なければ切り替える / お金: 0円 / 注意: 切り替えを忘れると、本番では何も起きないまま / 後から変える: ◎
  - C. 最初から全部自動 — 見え方: 何もしなくても動く。1回に送る件数などに上限を付ける / お金: 0円 / 注意: 間違いに気づくのが遅れると、被害が広がる / 後から変える: ◎
  - おまかせ → B。ただし、お金が動く・消す・買う操作だけは A(取り消せないものは、人の目を1回通すのが安全なため)
- **AI向けメモ**: お試しモードは設定(スクリプトプロパティや設定シート)の1か所で切り替え、宛先を本人に差し替える形で作る。切り替えの予定日を決めたことリストに書く。削除は「消す」ではなく別シートやアーカイブへの移動にする。上書き前に元の値を予備のシートへ。1回の処理件数に上限、二重実行防止(GAS なら LockService)。購入・送金・申込の自動実行は作らず、本人の確認ボタンを挟む。無料の Google アカウントの GAS はメール送信が1日100人まで(A4)なので、一斉送信には向かない。
- **完成チェック例**: 「お試しモードのまま[今すぐ動かす]を押すと、お客さんではなく自分のメールにだけ届き、表に『お試し』と記録される」

## A3. いつ動くか
- **重さ**: 聞く(依頼やステップ1の「完成のイメージ」で決まっていれば聞かず、そのきっかけと時刻を記録する)
- **当てはまる条件**: ②③
- **本人への聞き方**: 「これは、あなたがボタンを押したときに動けばいいですか? 毎朝など決まった時間ですか? それとも『メールが届いた』『フォームに回答があった』など、何かが起きたときですか?」
- **選択肢**:
  - A. ボタンを押したとき — 見え方: スプレッドシートのメニューやボタンを押すと、その場で動く / お金: 0円 / 注意: 押し忘れると動かない / 後から変える: ◎
  - B. 決まった時間に — 見え方: 毎朝7時台など、何もしなくても動く / お金: 0円のことが多い(パソコンの中で動かすときだけ有料。A4) / 注意: Google の中で動かす場合、「7時」に設定しても7時〜8時の間のどこかで動く / 後から変える: ◎
  - C. 何かが起きたとき — 見え方: フォームの回答やメールが来たら、すぐ(または数分後に)動く / お金: 0円〜(件数が多いと有料。A9) / 注意: つなぐサービスの無料の範囲では、気づくまでに最大15分ほどかかる / 後から変える: △
  - おまかせ → 依頼の言葉に合わせる。迷えば A で始めて、慣れたら B に(押して確かめながら使えるため)
- **AI向けメモ**: 答えは youken.md の上半分に「## 動くタイミング」を足して書く。GAS の時間主導型トリガーは指定時刻から1時間以内のどこか(以後その時刻を維持) https://developers.google.com/apps-script/guides/triggers/installable (2026-10-02確認)。分単位の正確さが要るなら本人に伝えるか、別の置き場所にする。フォーム送信・編集時はインストール型トリガー。Zapier Free・Make Free はどちらも15分間隔(A1)。Cloudflare Workers の定期実行は無料プランで1アカウント5個まで https://developers.cloudflare.com/workers/platform/limits/ 。B・C でも、確かめ用の[今すぐ動かす]ボタンを付ける。
- **完成チェック例**: 「確かめ用の[今すぐ動かす]を押すと、1分以内に結果が表に出る」。あとで確かめること: 「翌朝、何も触らずに表を開くと、今朝の分が増えている」

## A4. どこで動かすか
- **重さ**: AIが決めて記録(決まった時間や何かが起きたときに動くなら、パソコンを閉じていても動く B か C に決める。パソコンの中のファイルやアプリを操作する依頼のときだけ聞く)
- **当てはまる条件**: ①③
- **本人への聞き方**: 「夜や外出中など、パソコンを閉じている間にも動いてほしいですか?」
- **選択肢**:
  - A. 自分のパソコンで動かす — 見え方: パソコンの中のファイルやアプリも操作できる / お金: 自分で実行ボタンを押すなら0円。決まった時間に自動で動かすなら有料の許可(ライセンス)が要り、月約2,500円(税込・1年契約) / 注意: パソコンの電源が入っていて、ログインしている間しか動かない / 後から変える: △
  - B. Google の中で動かす — 見え方: パソコンを閉じていても動く。スプレッドシート・Gmail・Googleカレンダーと相性がよい / お金: 0円 / 注意: 1回6分まで、1日合計90分まで、メールは1日100人まで、などの上限がある / 後から変える: △
  - C. インターネット上の場所を借りる — 見え方: パソコンを閉じていても動き、Google 以外のサービスともつなぎやすい / お金: 1日10万回までは0円。超えたら月約800円〜(ドル払い・税抜) / 注意: 設定や合言葉の管理が少し増える / 後から変える: △
  - おまかせ → B(無料で、パソコンを閉じていても動き、結果を表で見られるため)。Google と関係のない作業なら C。パソコンの中のファイルを使うなら、まず Google ドライブに置けないかを考え、無理なら A
- **AI向けメモ**: GAS の上限(無料 Google アカウント / Google Workspace): メール宛先 100/日 / 1,500/日、トリガー合計実行時間 90分/日 / 6時間/日、1回の実行6分、トリガー20個/ユーザー/スクリプト、URL Fetch 2万回/日 / 10万回/日。「予告なく変わることがある」と明記 https://developers.google.com/apps-script/guides/services/quotas (2026-10-02確認)。6分を超える処理は分割して続きから再開する作り。Power Automate for desktop(Windows 10/11)は、無料ライセンスで使えるのは自分で実行ボタンを押すローカルの有人実行だけ https://www.microsoft.com/ja-jp/area/biz/smb/column-power-automate-desktop 。決まった時間に自動で動かす場合: パソコンにサインインしたまま(有人)なら Power Automate Premium(¥2,248/人/月相当・税抜・年払い)が要る。サインアウト中・ロック中も動かす無人実行は、Premium に加えて Process ライセンス(¥22,488/台/月相当・税抜・年払い)が要る(合計 約¥24,700/月・税抜。マシンの登録も Premium のユーザーが行う) https://learn.microsoft.com/ja-jp/power-platform/admin/power-automate-licensing/types (2026-09-22 更新)、https://www.microsoft.com/ja-jp/power-platform/products/power-automate/pricing (2026-10-02確認)。Mac で動かす場合はスリープでも止まる。Cloudflare Workers: Free 10万リクエスト/日、Paid は最低 $5/月 https://developers.cloudflare.com/workers/platform/pricing/ 。
- **完成チェック例**: あとで確かめること: 「パソコンを閉じたまま翌朝を迎え、スマホでスプレッドシートを開くと、決まった時間の分の結果が入っている」

## A5. 他のサイトから情報を読み取る(規約と法律)
- **重さ**: 条件次第(他人のサイトやサービスから情報を自動で読み取るときに聞く。ステップ1で届け先が自分と仲間だけと分かっていれば A に決めて記録し、聞かない)
- **当てはまる条件**: ③④⑤
- **本人への聞き方**: 「読み取った情報は、あなたと仕事仲間が見るだけですか? それとも、お客さんに見せたり、ホームページや SNS に載せたりしますか?」
- **選択肢**:
  - A. 自分と仕事仲間が見るだけ — 見え方: 集めた情報の要点が、自分と仲間にだけ届く(表・LINE・メールなど) / お金: 0円 / 注意: 相手サイトの利用規約で自動の読み取りが禁止されていたら、別の方法(相手の公式の窓口や手作業)にする / 後から変える: △ 公開に広げるときは、情報源ごとに条件を確かめ直す
  - B. お客さんや一般の人に見せる・公開する — 見え方: 他のサイトから集めた情報が、自分のページやボットに出る / お金: 0円〜(相手に使用料を払う場合あり) / 注意: 文章や写真をそのまま出すと著作権の侵害になるおそれがある。相手の許可か、相手が認めた方法が要る / 後から変える: ◎
  - おまかせ → A(まず自分たちで見るだけにし、公開したくなったら相手の条件を確かめてから広げる)
- **AI向けメモ**:
  - 方法は「相手の公式の窓口(API)・RSS・データ提供」を最優先、画面の読み取りは最後。利用規約で自動取得が禁止なら使わない(契約違反でアカウント停止・損害賠償のおそれ)。robots.txt は法律ではないがサイトの意思表示として従う。
  - ニュース・ブログ記事のまとめ: 既定は、各社が配っている新着一覧(RSS)の見出しと紹介文+元記事へのリンクだけを使い、本文は読み込まない。本文を要約して仲間に配る用途は、私的使用(30条)にも30条の4にも当たらず、要約が元の表現を残していれば翻案になりうる。有料記事・ログインが要る記事は使わない。使う情報源と、各社の RSS の利用条件(個人利用に限る、など)を確かめた結果を youken.md の「外部サービスと料金の前提」に書き、確かめきれないものは「未確定・あとで確認すること」と上半分の「やらないこと」に反映する。見出しも、営利で継続して無断で配信すると不法行為とされた例がある(知財高判 2005-10-06 ヨミウリ・オンライン事件)ので、B では相手の許可を前提にする。
  - 著作権法30条の4は情報解析など「享受を目的としない利用」を許諾なしで認めるが、享受目的が少しでも併存すると適用されず(記事の本文や写真を人に読ませる・表示する用途は対象外)、著作権者の利益を不当に害する場合(例: AI 学習用の収集を robots.txt 等で拒み、データベースとしての販売が推認されるサイトから、それを回避して集める)も除かれる(文化庁「AIと著作権に関する考え方について」2024-03-15 https://www.bunka.go.jp/seisaku/chosakuken/aiandcopyright.html 、2026-10-02確認)。価格・数値などの事実そのものは著作物に当たらないことが多いが、規約は別問題。
  - ログインが要るページは、他人の ID・パスワードの無断使用は不正アクセス禁止法違反、自分の ID でも規約で自動操作を禁じていることが多い。負荷: 2010年の岡崎市立中央図書館事件(約1秒に1回の取得で偽計業務妨害容疑で逮捕、のち起訴猶予)を踏まえ、数秒以上あけて回数も絞る。人の名前・連絡先などを集めて仕事に使うなら個人情報保護法の対象(小規模でも事業で使えば。利用目的の公表など)なので避ける。判断に迷う規約・用途は、本人に専門家(弁護士)への相談をすすめ、「未確定・あとで確認すること」に書く。
- **完成チェック例**: 「集めた表(または届いたまとめ)を開くと、見出し・数字・要点とリンクだけが入っていて、相手サイトの本文や写真はそのまま入っていない」

## A12. 合言葉(APIキー)の置き場所と管理
- **重さ**: AIが決めて記録
- **当てはまる条件**: ④
- **本人への聞き方**: (聞かない。決めたことリストに「サービスの合言葉は、画面や表に出ない場所にしまう。あなたは AI が用意した[設定]画面に貼るだけで、チャットには貼らない。漏れたら作り直す手順は要件書の下半分」と一行で残す)
- **AI向けメモ**: GAS はスクリプトプロパティ(PropertiesService)に置き、セルやコードに直書きしない。[設定]画面はスプレッドシートのメニューから開く入力欄にし、保存後は値を表示しない。スプレッドシートの編集者はスクリプトも開けるので、編集者は必要な人だけに。Workers は secret、手元で動かすなら .env+.gitignore。Zapier・Make はサービス側の「接続」機能に任せる。対象: LINE のチャネルアクセストークンとチャネルシークレット、Slack の Webhook URL とボットトークン、外部 API キー。漏れたときの再発行手順を youken.md の「運用の手順」に書く。
